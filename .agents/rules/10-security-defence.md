# 10: SECURITY & DEFENCE

**NEVER USE:**
- Real Army operational positions
- Classified coordinates
- Sensitive routes
- Targeting data
- Weapons data
- Live surveillance
- Operational force dispositions

**ALLOWED:**
- Public roads
- Public elevation (SRTM)
- Public weather (Open-Meteo, NOAA)
- Public hazard information
- Synthetic logistics state

*Any ambiguous source must be classified as: UNKNOWN / DO NOT USE until verified.*
