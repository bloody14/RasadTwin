# 20: DATA GOVERNANCE

**STRICT DATA CLASSES:**
1. PUBLIC_REAL
2. SYNTHETIC
3. RESTRICTED
4. SECRET

**DATASET ONBOARDING:**
For every new dataset, require:
- Provider
- Dataset name
- Purpose
- License
- Download date
- Version / date range
- Spatial scope
- Processing
- Provenance
- Retention

**CONTENT RULES:**
- Real public data can describe geography and environment.
- Synthetic data MUST represent posts, inventory, demand, fleet, operational priorities, and fictional disruptions.
