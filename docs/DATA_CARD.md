# RasadTwin Data Card

**Dataset Classification**: Synthetic / Illustrative

## Overview
The experimental world for RasadTwin is generated by the HimalayaSim simulator (`src/rasadtwin/sim/`). All data are strictly synthetic, fictional, and illustrative. They are intended only for simulation, research prototyping, and validation of the RasadTwin predictive logistics framework.

## Data Origin
- **Generator**: HimalayaSim (Phase P1)
- **Source**: Entirely procedurally generated using seeded random number generators
- **Real-world basis**: None. All locations, rates, and parameters are fictional.

## Contents
| Table | Description |
|---|---|
| nodes | Fictional depot and forward-post locations with altitude |
| edges | Transport links (road, mule, heli, drone) with fictional distances |
| weather | Synthetic seasonal temperature, snowfall, wind, visibility |
| demand | Synthetic daily demand D[p,i,t] per item per post |
| inventory | Daily stock, consumption, replenishment, stockout state |
| disruptions | Road closures, landslides, heli/drone grounding events |

## Items Modeled
- rations, POL (fuel), medical, spares
- **No weapons or ammunition are modeled.**

## Constraints
- NO real, classified, or sensitive military data is present.
- NO personally identifiable information is used.
- All locations, unit dispositions, supply norms, routes, vulnerabilities, capacities, and operational schedules are entirely fictional and illustrative.
- Consumption rates are arbitrary illustrative values, not sourced from any military standard.
- Weather parameters are simple sinusoidal models, not a real Himalayan climate model.

## Reproducibility
Each generated dataset records:
- git commit hash
- configuration hash
- random seed
- timestamp
- Python version

Same seed + same config → identical output.

## Intended Use
- Internal simulation for RasadTwin prototype development
- Research experimentation and algorithm benchmarking against synthetic baselines
- Demonstration of predictive logistics concepts

## Known Limitations
- The synthetic world does not replicate real terrain, weather, or logistics behavior.
- Results from this simulator should not be interpreted as predictions of real military logistics performance.
- Future validation against real-world (non-classified) logistics data is outside the current phase scope.
