# RasadTwin Governance Pack

This pack is designed to keep an agentic coding session aligned over long periods.

## Core files

- `AGENTS.md` — agent constitution and authority hierarchy.
- `SECURITY.md` — security/data protection policy.
- `docs/SECURITY_POLICY.md` — machine-oriented security rules.
- `docs/DECISION_POLICY.md` — what the agent may decide vs where it must stop.
- `docs/CHANGE_CONTROL.md` — protected-change process.
- `docs/STATE.md` — persistent project state.
- `docs/CHANGELOG.md` — approved governance changes.

## Suggested placement

Copy `AGENTS.md` to the repository root.
Copy `SECURITY.md` to the repository root.
Copy `docs/*` into the repository `docs/` directory.
Copy `.agents/rules/*` and `.agents/workflows/*` if the installed Antigravity version supports those folders.

## Important

This pack is engineering governance. It is not a military security certification and does not make the software compliant with any classified-system standard.
